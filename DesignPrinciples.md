# AgencyOS Design Principles

## Philosophy

AgencyOS is designed to feel calm, structured, and dependable.
The interface emphasizes clarity over decoration.

## Colors

- Indigo is the primary accent.
- Stone is the neutral palette.
- Semantic colors are used sparingly.

## Borders

- Thin borders define structure.
- Shadows are avoided.

## Shape

- All UI elements use `rounded-sm`.

## Spacing

- Whitespace creates hierarchy.
- Avoid visual clutter.

## Motion

- Fast, subtle transitions only.
- No unnecessary animations.

## Components

- All UI elements are built from reusable Blade components.
